# 枝析

在本机浏览器中处理文字、阅读网页，并围绕一个问题搜集资料、生成报告。可使用本地模型，也可连接自己的 OpenAI 兼容模型 API。

- **文本与文件**：粘贴文字或导入文本文件，提取内容、查看结构并编辑结果。
- **网页分析**：提交网址，阅读页面内容与重要链接。
- **自主研究**：输入研究目标，可补充文字、文本文件和起始网址，设置资料搜集时限。
- **报告与任务**：查看材料和原文、划选追问、编辑与保留版本；从队列和历史查看任务，暂停或继续处理。

## 环境要求

本项目的安装和启停脚本面向 **Windows 与 Python 3.12**。准备浏览器，以及以下任意一种分析模型运行方式：

| 模型方式 | 需要自行准备 |
| --- | --- |
| 模型 API | OpenAI 兼容的 Chat Completions 服务、模型名及凭据 |
| 本地 GGUF | 模型文件，以及支持该模型和本机硬件的 `llama-server.exe` |
| 本地 Hugging Face 模型 | 完整模型目录，以及能够加载该模型的 PyTorch、Transformers 推理环境 |

`setup.bat` 只安装网页后台依赖，不包含模型权重、Python、Torch、Transformers 或 llama.cpp。CPU、内存和显存需求取决于所选模型与任务；使用模型 API 时，不需要在本机加载模型。

安装依赖需要联网；读取网页和公开搜索需要相应网络访问。处理本地文字可使用本地模型，不需要公开搜索。

## 下载和启动

1. 在本仓库点击 **Code → Download ZIP**，完整解压。也可以使用 Git 克隆本仓库。请勿在压缩软件内部直接运行。
2. 准备 Python 3.12，双击 `setup.bat`。依赖会安装到项目目录的 `.venv/`。
3. 安装完成后，双击 `start.bat`。浏览器会打开 <http://127.0.0.1:8177>；没有自动打开时手动访问该地址。
4. 点击右上角 **设置**，添加自己的模型配置，再在提交任务时选用。

无需另行下载 Release 附件，也不要直接双击 `static/index.html`：网页需要通过本项目的后台服务使用。未配置模型时可以打开界面和设置，但分析任务需要可用的模型。

如果电脑没有 `py -3.12` 命令，可在项目文件夹的**命令提示符**中指定已安装的 Python，再安装：

```bat
set "WP_SETUP_PYTHON=E:\Python312\python.exe"
setup.bat
```

将示例路径替换为自己的 Python 3.12 路径。依赖版本见 [requirements.txt](requirements.txt)。

## 配置分析模型

在 **设置 → 分析模型 → 添加模型** 中保存配置。可以保存多个配置，并在每次提交任务时选择，不必修改源代码。

### 模型 API

模型来源选择 **OpenAI 兼容 API**，填写配置名称、Base URL、模型名和 API Key，然后点击 **验证并保存**。

Base URL 应包含服务要求的路径前缀，例如 `https://api.example.com/v1`。程序会在其后追加 `/chat/completions`；也接受以 `/chat/completions` 结尾的完整地址。这里的地址仅为格式示例，不是可用服务。

模型服务也可以部署在自己机器或自己的服务器上。连接外部服务时，任务输入及所需材料会发送给所选模型服务；费用和数据处理方式取决于该服务。

### 本地 GGUF

1. 自行准备 `.gguf` 模型和匹配的 `llama-server.exe`。
2. 将 [local-config.example.bat](local-config.example.bat) 复制为同目录的 `local-config.bat`，去掉所需行前的 `rem`，填写运行器路径，例如：

   ```bat
   set "LLAMA_CPP_SERVER=E:\llama.cpp\llama-server.exe"
   ```

3. 重新启动本项目。在模型设置中选择 **本地模型**，填写模型的绝对路径，例如 `E:\Models\my-model.gguf`，然后验证并保存。

若 `llama-server.exe` 已加入系统 PATH，也可以不填写运行器路径。模型可填写单个 GGUF 文件，或只含一个 GGUF 的文件夹；文件夹包含多个 GGUF 时，请指定实际使用的文件。

`WP_MODEL_PATH` 可用于设置默认模型路径，实际任务仍以选择的配置为准。模型和运行器不会由本项目自动下载。

### 本地 Hugging Face 模型

准备包含 `config.json`、分词器及权重的完整本地模型目录。在自己的推理环境中安装与模型、硬件匹配的 PyTorch 和 Transformers，确保模型可由 `AutoModelForCausalLM` 与 `AutoTokenizer` 加载。

在 `local-config.bat` 中指定该环境的 Python：

```bat
set "WP_MODEL_PYTHON=E:\model-env\Scripts\python.exe"
```

重新启动后，在模型设置中填写模型目录的绝对路径。不要只填写模型名称或在线仓库名。

## 配置网页搜索

**分析模型与搜索服务是两项独立配置。** 模型 API 的密钥不能直接当作搜索 API 的密钥。

在 **设置 → 网页搜索** 中选择：

- **普通网页搜索**：使用百度、360、Yahoo 的网页搜索入口，无需搜索密钥，可能受验证码、限流和网络条件影响。
- **百度搜索 API 或 Brave Search API**：使用自己的对应服务密钥，并自行确认服务费用。

保存搜索设置不会启动研究。界面中的单次检索测试会发送真实请求，选择付费 API 时可能计费。手动填写的搜索密钥保留在后台内存，关闭服务后需要重填；也可通过启动环境变量 `WP_BAIDU_SEARCH_API_KEY`、`WP_BRAVE_SEARCH_API_KEY` 提供。

研究中的 **公开搜索主题** 会发送到搜索服务，只填写允许公开的主题和关键词。没有公开检索需要时，可只读附加材料；选择起始网址时，按界面提供的联网范围设置读取方式。

## 开始使用

### 处理文字或网页

在输入区选择文本或网页，粘贴内容、导入文本文件或填写网址，选择模型和所需结构后提交。结果页可查看、编辑内容及回查原文；已有任务运行时仍可提交下一项。

### 创建研究

输入要研究的问题，例如“比较居家办公与办公室办公的主要差异”。按需要添加背景文字、文本文件和起始网址；允许公开搜索时，填写可公开的搜索主题，选择模型并设置资料搜集时限后提交。

搜集时限用于资料搜集，不等于整个任务的总时长；到时后还需要整理报告。已有材料不足、网站无法访问等情况会影响实际覆盖范围。

### 查看任务与报告

- **任务队列**：查看进度和详情，使用对应按钮暂停或继续。清出队列不等于删除历史记录。
- **历史记录**：进入研究详情，从中阅读已有报告和材料。
- **报告页面**：回查原文、划选提问或编辑内容；已有版本仍可查看。
- **任务运行中心**：打开 <http://127.0.0.1:8177/ops>，搜索任务、分页浏览并查看处理过程。

模型生成的解释可能出错，重要结论应结合所附来源判断。网页访问受站点权限、登录、付费与反爬限制影响；发现媒体链接也不等于已读取视频画面或音乐内容。

## 停止和保存数据

运行 `stop.bat`，按提示确认后停止本项目后台。关闭浏览器标签页不会停止服务。需要保留任务现场时，先在界面暂停任务，再停止服务。

默认生成的文件保存在项目目录内：

| 位置 | 内容 |
| --- | --- |
| `data/` | 历史、任务、报告及材料等运行数据；主数据库为 `history.sqlite3` |
| `data/logs/server-startup.log` | 后台启动日志 |
| `.venv/` | 网页后台的 Python 环境 |
| `.runtime/` | 临时文件和缓存位置 |
| `local-config.bat` | 自己的路径与环境配置 |

备份时先停止服务，再复制 `data/`。更新源码时保留自己的数据和配置，不要用其他人的数据库覆盖。上述运行数据和配置可能包含私人信息，不应上传到公开仓库。

## 常见问题

| 情况 | 处理方式 |
| --- | --- |
| `setup.bat` 失败 | 检查 Python 3.12、终端错误及依赖下载网络；没有 Python Launcher 时使用上面的 `WP_SETUP_PYTHON` 方法 |
| 双击 `start.bat` 后网页未打开 | 手动访问本机地址，并查看 `data/logs/server-startup.log`；确认 8177 端口没有被其他应用占用 |
| 找不到本地模型或运行器 | 使用绝对路径；检查 `local-config.bat` 的实际文件扩展名与运行器路径，修改后重启后台 |
| 缺少 Torch 或 Transformers | 安装脚本只安装网页依赖；通过 `WP_MODEL_PYTHON` 指向自己准备好的推理环境，或改用模型 API |
| 内存或显存不足 | 释放自己不需要的程序，换用资源要求更低的兼容模型，或使用模型 API |
| 搜索失败、403 或验证码 | 检查搜索配置和目标网站访问条件；可更换搜索服务、提供可访问的起始网址，或导入已经取得的文字 |
| 重启后 API 密钥不可用 | 在自己的会话中重新填写密钥；搜索密钥也可通过上述环境变量提供 |
